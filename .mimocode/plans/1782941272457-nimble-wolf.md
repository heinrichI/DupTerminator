# Исправление: RebuildAllContainerFiles портит данные после десериализации

## Корневая причина

`TestFactory.LoadFromJson()` при загрузке Zorro.json:
1. Десериализует JSON через `SerializationHelpers.DeserializeChecksumDictionary()` — **корректно** восстанавливает все типы и `Container.Files`
2. Вызывает `RebuildAllContainerFiles()` — **перезаписывает** `Container.Files` на основе файлов из словаря чексумм

Проблема: в словаре чексумм есть только файлы, у которых есть **дубликаты** (одинаковая чексумма с другим файлом). Уникальные файлы (без дубликатов) отсутствуют. Поэтому `RebuildAllContainerFiles` создаёт неполные `Files`-массивы.

### Пример с 003 и 004
- 003.cbr содержит ~20 страниц, 004.cbr содержит ~20 страниц
- В словаре чексумм есть только 1 совпадение между ними (1 страница с одинаковой чексуммой)
- `RebuildAllContainerFiles` создаёт Files = [1 файл] для каждого вместо [20 файлов]
- Pass 2.5 видит: `equalFilesCount(1) == totalFilesFirst(1) == totalFilesSecond(1)` → TheyThemselvesAreEqual=True
- **Неверный результат**: два разных архива помечены как идентичные

### Почему в реальной программе работает
Программа сканирует файлы с нуля и строит полный словарь чексумм, где **все** страницы присутствуют. `Container.Files` заполняется корректно.

## Исправление

### Файл: `DupTerminator.Test/TestFactory.cs`

Для JSON с `$type` дискриминаторами **не вызывать** `RebuildAllContainerFiles` — десериализатор уже корректно восстанавливает `Container.Files`.

```csharp
private static ConcurrentDictionary<string, IList<ExtendedFileInfo>> ReconstructFromPolymorphic(string json)
{
    var dict = SerializationHelpers.DeserializeChecksumDictionary(json);
    // Не вызываем RebuildAllContainerFiles — десериализатор уже восстановил Container.Files
    return dict;
}
```

`RebuildAllContainerFiles` оставить только для `ReconstructFromElements` (старый JSON без `$type`).

### Файл: `DupTerminator.Test/SearcherMD5ContainerTests.cs`

Вернуть оригинальные assert'ы для Papyrus T22 (из PdfAndCbz.json), так как Zorro.json теперь должен работать правильно.
